# Sedona — Информационный туристический портал городка Седона

[Посмотреть Live Demo](https://irynaglytsko.github.io/Sedona/)

Современный, адаптивный и интерактивный веб-сайт, разработанный в качестве гида по американскому городку Седона (Аризона). Проект предоставляет пользователям информацию о достопримечательностях, преимуществах отдыха в регионе, а также содержит интерактивный модуль для подбора и бронирования номеров в гостиницах. Разработан в соответствии с профессиональными стандартами качества коммерческой верстки.

---

## 🚀 Описание проделанной работы

В ходе работы над проектом был реализован полноценный интерфейс главной страницы и внутренней страницы каталога отелей с глубокой проработкой интерактивных элементов:

### Реализованный функционал и секции:
*   **Шапка и Навигация (Header):** Фиксированная структурированная панель навигации с кастомным позиционированием логотипа по центру, кнопками быстрого поиска, счетчиком отелей в «Избранном» и призывом к действию (CTA) «Хочу сюда!».
*   **Промо-блок (Hero):** Эффектный стартовый экран с фоновым изображением скал Седоны, декоративной фигурной выручкой по нижнему краю и фирменным текстовым приветствием.
*   **Сетка преимуществ (Features):** Комбинированная раскладка текстовых блоков и графических изображений («Настоящий городок», «Небольшая площадь», «Красивая дорога» и др.), выполненная в контрастной фирменной палитре.
*   **Блок услуг и особенностей (Amenities):** Минималистичная секция с кастомными векторными иконками, описывающая инфраструктуру города (Жилье, Еда, Сувениры).
*   **Интерактивный модуль поиска (Hotel Search):** Информационный блок с триггером «Поиск гостиницы в Седоне», активирующим **всплывающее модальное окно**.
*   **Модальное окно бронирования:** Кастомная форма с полями выбора дат заезда/выезда, интерактивными счетчиками количества гостей (Взрослые/Дети) с кнопками «плюс/минус» и валидацией данных.
*   **Форма подписки (Newsletter):** Блок подписки на рассылку с адаптивным фоновым изображением и стилизованным текстовым инпутом.
*   **Подвал сайта (Footer):** Трехколоночный футер, включающий блок кастомных иконок социальных сетей (ВКонтакте, Telegram, YouTube), кликабельный номер телефона службы поддержки и логотип-ссылку разработчика.

## 🛠 Технологический стек

Проект разработан на базе современных стандартов фронтенд-разработки с упором на чистый код и независимую компонентную архитектуру:

*   **HTML5:** Валидный, семантически корректный код. Применяются логические теги разметки (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer_>`, `<button>`). Элементы форм и интерактивные кнопки спроектированы с учетом базовых требований доступности (Accessibility).
*   **CSS3 (SCSS / Flexbox / Grid):**
    *   **Методология БЭМ (Блок, Элемент, Модификатор):** Вся структура стилей организована по правилам БЭМ, что гарантирует изолированность компонентов, предотвращает конфликты стилей и делает код легко поддерживаемым.
    *   **Flexbox & CSS Grid:** Использованы для построения адаптивных шахматных сеток в блоке преимуществ и выравнивания элементов интерфейса.
    *   **Кастомная стилизация:** Кастомные элементы форм, плавные переходы (transitions) при наведении курсора на кнопки, ссылки и карточки.
*   **JavaScript (ES6+):**
    *   Реализация логики открытия и закрытия модального окна поиска гостиниц по клику на кнопку.
    *   Программирование кастомных счетчиков количества гостей (логика инкремента и декремента для кнопок плюс/минус).
    *   Базовая валидация пустых полей формы перед отправкой данных.
*   **GitHub Pages:** Быстрый автоматический деплой и публикация проекта в сети.

## 📈 Оптимизация и стандарты верстки

*   **Кроссбраузерность и Pixel Perfect:** Сайт отображается абсолютно идентично во всех современных браузерах (Chrome, Firefox, Safari, Edge) и строго соответствует сетке графического макета.
*   **Векторная графика (SVG):** Все иконки, логотипы и декоративные элементы интерфейса внедрены в формате SVG, что сохраняет идеальную четкость на Retina-дисплеях и экранах высокой плотности.
*   **Шрифты:** Подключены современные оптимизированные веб-шрифты с правильным распределением начертаний (Regular, Medium, Bold) для соблюдения иерархии типографики.

## 💻 Локальное развертывание

Чтобы запустить и протестировать этот проект локально на своем компьютере:

1. Склонируйте данный репозиторий:
   ```bash
   git clone https://github.com
   ```

2. Перейдите в каталог проекта:
   ```bash
   cd Sedona
   ```

3. Откройте файл `index.html` в любом браузере или воспользуйтесь расширением *Live Server* в среде разработки Visual Studio Code.
